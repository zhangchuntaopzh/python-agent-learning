# 首页头像响应式网格设计

## 目标

让首页的四个陪伴头像在所有小程序终端宽度下稳定显示为两行两列，同时保持图片比例与既有选择交互。

## 布局

- 保留现有四个头像的顺序、标签、点击选择和选中状态。
- 头像容器继续使用 Flex 布局，但改为两端对齐。
- 每个头像选项宽度固定为容器的 `48%`，从而避免固定间距与 `calc()` 在窄屏下产生的取整或溢出问题。
- 头像图片改为相对选项宽度，并设置最大显示尺寸；`mode="aspectFit"` 保持原图比例，不裁切、不拉伸。
- 不添加断点或单列回退：无论屏幕宽度，四项都显示为两列，因而为两行两列。

## 验证

1. 自动检查头像网格采用 `justify-content: space-between` 与 `width: 48%`，图片使用相对宽度和最大尺寸。
2. 既有四个头像、默认选择、选择后进入测评的测试必须继续通过。
3. 在微信开发者工具的不同设备模拟器宽度中确认：每行两个头像、图片完整显示、标签可读且点击区域正常。

## 范围边界

- 只修改首页头像网格的样式和对应测试。
- 不修改头像图片、题目、计分、云开发、资讯页或原文访问逻辑。
