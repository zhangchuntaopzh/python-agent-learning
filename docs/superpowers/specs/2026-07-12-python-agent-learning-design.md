# Python Agent 入门学习资料：设计说明

## 目标

为零基础学习者提供一套可离线运行的中文 Markdown 教材和 Python 示例程序。学习者应能理解 Agent 的基本组成、一次任务如何流动，以及每个模块在程序中的职责。

## 范围

- 教材使用中文 Markdown 编写。
- 示例仅使用 Python 标准库，不要求安装第三方包、配置网络或申请 API Key。
- 程序实现单 Agent 的最小闭环：接收任务、规划、选择工具、执行工具、保存短期记忆、生成回答。
- 教材说明如何在理解基础版后替换为大模型 API，但不包含密钥或真实 API 调用。

## 不包含的内容

- 多 Agent 协作、网页自动化、向量数据库、长期持久化记忆。
- 生产级鉴权、监控、并发与部署。
- 对任何厂商 SDK 的绑定。

## 交付结构

```text
agent_学习资料/
├── README.md                 # 学习路线、环境准备和运行指引
├── 教程.md                    # 原理、架构、逐模块讲解、练习与升级路径
└── basic_agent/
    ├── main.py               # 程序入口与命令行交互
    ├── agent.py              # Agent 编排：思考—行动—观察循环
    ├── planner.py            # 将任务映射为计划和工具调用
    ├── tools.py              # 安全且确定性的计算与知识查询工具
    ├── memory.py             # 当前会话的短期记忆
    └── tests/                # 基础自动化测试
```

## 架构与数据流

1. 用户在命令行输入自然语言任务。
2. `Agent` 将任务交给 `Planner`；规划器根据关键词产生一个计划与可执行动作。
3. `Agent` 从 `ToolRegistry` 获取指定工具并执行。
4. 工具输出成为“观察结果”；`Agent` 将任务、计划、动作和结果写入 `Memory`。
5. `Agent` 把观察结果整理为最终中文回答并显示给用户。

以确定性规则模拟“模型决策”是本项目的有意设计：学习者能看到每一步的输入与输出，而不会被模型随机性或账号配置遮挡原理。

## 模块职责

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `main.py` | 启动交互、读取用户任务、打印结果 | `Agent` |
| `agent.py` | 编排完整循环与异常处理 | Planner、工具、Memory |
| `planner.py` | 识别计算、知识查询或普通对话任务；输出计划 | 无 |
| `tools.py` | 提供受限表达式计算、内置知识查询 | 标准库 |
| `memory.py` | 保存和格式化本轮会话记录 | 标准库 |

## 错误处理与安全边界

- 不执行任意 Python 或系统命令。
- 计算器只接受数字、运算符和括号，并通过 AST 白名单求值。
- 未识别任务会返回解释性提示，而不是猜测执行。
- 单个工具出错不会使交互程序崩溃，错误会被转化为可读反馈。

## 验证标准

- 在 Python 3.10+ 环境中，运行入口即可交互使用。
- 自动化测试覆盖计算、知识查询、规划分支、记忆写入和未知任务处理。
- 教程中每个模块都有“作用、输入、输出、关键代码解释”四部分。

## 学习路径

1. 先运行三条内置示例命令，观察完整循环。
2. 阅读架构图与模块说明。
3. 修改内置知识库或添加一个工具。
4. 将规则型规划器替换为大模型 API 调用，并保留工具与记忆接口。
