# Python Agent 入门学习资料：设计说明

## 目标

为零基础学习者提供一套可离线运行的中文 Markdown 教材和 Python 示例程序。学习者应能理解 Agent 的基本组成、一次任务如何流动，以及每个模块在程序中的职责。程序配套一个动态流程可视化界面，将真实运行步骤、模块状态与变量传递直观展示出来。

## 范围

- 教材使用中文 Markdown 编写。
- 示例仅使用 Python 标准库，不要求安装第三方包、配置网络或申请 API Key。
- 程序实现单 Agent 的最小闭环：接收任务、规划、选择工具、执行工具、保存短期记忆、生成回答。
- 可视化页面按真实执行事件播放流程，支持自动播放、暂停、上一步、下一步和重置。
- 页面提供“启用大模型模拟”开关；开启后，需理解任务或润色最终回答的步骤会经过一个离线的大模型模拟节点。
- 教材说明如何在理解基础版后替换为大模型 API，但不包含密钥或真实 API 调用。

## 不包含的内容

- 多 Agent 协作、网页自动化、向量数据库、长期持久化记忆。
- 生产级鉴权、监控、并发与部署。
- 对任何厂商 SDK 的绑定。

## 架构与数据流

1. 用户在命令行输入自然语言任务。
2. `Agent` 将任务交给 `Planner`；规划器根据关键词产生一个计划与可执行动作。
3. `Agent` 从 `ToolRegistry` 获取指定工具并执行。
4. 工具输出成为“观察结果”；`Agent` 将任务、计划、动作和结果写入 `Memory`。
5. `Agent` 把观察结果整理为最终中文回答并显示给用户。

每个关键步骤同时产生一个 `RunEvent`。本地网页读取这些事件，并按时间顺序驱动可视化：当前模块高亮且显示“正在运行”；连线上的光点从来源模块移动到目标模块；光点旁展示本步传递的变量名和值摘要，例如 `task`、`plan`、`tool_name` 和 `tool_result`。

开启“大模型模拟”后，`Agent` 还会产生 `规划器 → 大模型模拟 → 规划器` 与 `记忆 → 大模型模拟 → 最终回答` 的事件。事件变量展示模拟 API 的 `model`、`messages` 和 `response` 摘要。模拟器完全在本地以确定性规则返回结果，不请求网络、不读取密钥、不产生费用。

以确定性规则模拟“模型决策”是本项目的有意设计：学习者能看到每一步的输入与输出，而不会被模型随机性或账号配置遮挡原理。

## 模块职责

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| `main.py` | 启动交互、读取用户任务、打印结果 | `Agent` |
| `agent.py` | 编排完整循环与异常处理 | Planner、工具、Memory |
| `planner.py` | 识别计算、知识查询或普通对话任务；输出计划 | 无 |
| `tools.py` | 提供受限表达式计算、内置知识查询 | 标准库 |
| `memory.py` | 保存和格式化本轮会话记录 | 标准库 |
| `llm_simulator.py` | 模拟聊天模型 API 的请求与确定性响应 | 标准库 |
| `events.py` | 定义和收集运行事件，隔离核心逻辑与界面 | 标准库 |
| `web_server.py` | 用标准库启动本地服务，接收任务并返回事件 | Agent、标准库 |
| `static/` | 绘制 Agent 模块图、控制播放并展示变量 | 浏览器原生能力 |

## 错误处理与安全边界

- 不执行任意 Python 或系统命令。
- 计算器只接受数字、运算符和括号，并通过 AST 白名单求值。
- 未识别任务会返回解释性提示，而不是猜测执行。
- 单个工具出错不会使交互程序崩溃，错误会被转化为可读反馈。
- 可视化仅展示摘要化变量，超长文本会截断，避免信息淹没流程。
- 模拟 API 开关默认关闭；即使开启，也不得访问网络、环境变量或任何真实密钥。

## 验证标准

- 在 Python 3.10+ 环境中，运行入口即可交互使用。
- 自动化测试覆盖计算、知识查询、规划分支、记忆写入和未知任务处理。
- 自动化测试验证事件顺序和关键变量；页面可在本机浏览器中手动验证播放、单步与重置。
- 自动化测试验证开关开启时的模拟 API 事件、变量与离线行为。
- 教程中每个模块都有“作用、输入、输出、关键代码解释”四部分。

## 学习路径

1. 在可视化页面运行三条内置示例命令，观察完整循环与变量传递。
2. 阅读架构图与模块说明。
3. 修改内置知识库或添加一个工具。
4. 将规则型规划器替换为大模型 API 调用，并保留工具与记忆接口。
