# 焦虑自评小程序头像选择设计

## 目标

将四个本地 PNG 头像接入焦虑自评小程序。用户在首页开始答题前选择一个头像；选中的头像在结果页显示，并在重新测评时保留。

## 范围与隐私

- 头像资源保存在 `anxiety-self-check-miniprogram/assets/avatars/`，均为 144×144 PNG，且小于 2 MB。
- 头像选择仅存在当前小程序内存中；不登录、不联网、不上传、不写入本地存储。
- 不改变题目、计分、分级或安全提示。

## 用户流程

1. 首页在“开始自评”按钮前显示四个头像。
2. 第一个头像为默认选择；点击任一头像后显示清晰的选中描边与无障碍文本提示。
3. 点击“开始自评”时，选择通过页面参数传入答题页。
4. 答题页在跳转结果页时继续传递头像标识。
5. 结果页显示选择的头像；点击“重新测评”时带回同一头像。

## 实现边界

- 新增 `utils/avatars.js` 作为唯一的头像清单与 ID 校验来源。
- 首页、答题页和结果页只传递受 `getAvatar()` 校验的头像 ID，不直接信任页面参数。
- 结果页在头像 ID 无效或缺失时回退为默认头像。

## 验证

1. 自动测试头像清单数量、默认头像和无效 ID 回退。
2. 自动检查首页的选择控件、结果页的头像展示，以及路由参数传递代码。
3. 在微信开发者工具中选择非默认头像，完成答题，确认结果页显示同一头像；点击重新测评，确认头像保留。

## 设计自查

- 没有待定项或隐含的外部服务。
- 头像状态与既有答题状态分离；计分逻辑不受影响。
- 无效参数有明确的默认回退，且全程不持久化用户数据。
