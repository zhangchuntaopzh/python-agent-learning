# Python Agent 学习实验室

一个面向零基础学习者的、可离线运行的 Python Agent 示例。通过可视化流程图观察 Agent 如何理解任务、规划、调用工具、记录记忆并生成回答。

> 不需要 API Key、不联网、不依赖第三方 Python 包。

## 功能亮点

- 可视化 Agent 流程：用户输入、规划器、工具注册表、工具、记忆与最终回答。
- 动态数据流：运行时高亮当前节点，显示变量在模块间传递。
- 离线大模型模拟：可选择展示模拟的 `model`、`messages` 与 `response` API 流程。
- 安全计算器：通过 AST 白名单限制输入，不执行任意代码。
- 可交互学习：点击节点即可查看相应模块的核心实现代码。
- 零依赖测试：使用 Python 标准库 `unittest` 验证 Agent、工具、接口与布局行为。

## 快速开始

### 环境要求

- Python 3.10 或更高版本
- 现代浏览器（可视化版）

### 启动可视化版

```bash
cd agent_学习资料/basic_agent
python3 web_server.py
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。关闭终端即可停止服务。

建议依次输入：

```text
什么是 agent？
计算 (12 + 3) * 2
帮我开始学习
```

勾选“启用大模型模拟”后，流程会额外显示两次完全离线的模拟 API 调用；它不读取密钥、不产生费用。

### 启动终端版

```bash
cd agent_学习资料/basic_agent
python3 main.py
```

输入 `退出` 结束程序。

## 运行测试

```bash
cd agent_学习资料/basic_agent
python3 -m unittest discover -s tests -v
```

## Agent 工作流

```text
用户任务 → 规划 → 工具调用 → 观察结果 → 记忆 → 最终回答
```

可视化页面还展示了大模型在真实 Agent 中常见的位置：帮助理解任务、帮助组织最终回答。该项目用本地确定性模拟器代替真实网络 API，便于专注理解框架而非账号和费用配置。

## 学习路线

1. 运行三个示例任务，观察节点、连线与变量变化。
2. 阅读 [教程.md](教程.md)，理解每个模块的输入、输出与职责。
3. 在知识库中添加条目，或实现一个新工具。
4. 尝试将 `llm_simulator.py` 替换为真实模型 API，并保留工具验证边界。

## 安全说明

本项目只用于学习。计算器只允许数字、括号和基本运算，禁止函数调用、导入与系统命令。即使将来接入真实大模型，也应继续验证工具名称与参数，不能直接执行模型输出。
