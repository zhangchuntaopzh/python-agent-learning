# Web3 基础学习笔记

## 钱包与签名

钱包管理私钥和地址。连接 MetaMask 只是请求地址授权；发布留言时，钱包会展示交易内容并要求签名。私钥不应发送给网站。

## 交易与 Gas

`count()`、`getMessage()` 是读取，不改变链上状态，通常由 RPC 免费模拟。`post()` 改变状态，必须发送交易并支付 Gas。前端先 `estimateContractGas`，再由钱包签名并广播。

## Solidity

`MessageBoard` 使用 `struct` 保存作者、文本、时间；`event` 方便前端监听；`require` 限制留言长度。`external` 函数可由钱包调用，`view` 函数只读状态。

## Viem 与 React

Viem 的 `createPublicClient` 用于读与估算 Gas；`createWalletClient` 通过 MetaMask 请求账户并发送 `writeContract`。React 用状态保存地址、输入内容和交易哈希。
