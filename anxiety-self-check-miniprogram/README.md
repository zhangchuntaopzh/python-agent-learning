# 焦虑自评 Demo

这是一个本地使用的自我感受整理工具，不是医疗诊断；它不会收集、上传或保存答题数据。

## 自动验证

在本目录运行：

```bash
npm test
```

它会检查 7 道题、总分计算、各分数边界、页面注册及关键安全提示。

## 微信本地预览

1. 打开微信开发者工具，用自己的微信扫码登录。
2. 选择“导入项目”，项目目录选择本文件夹，开发模式选“小程序”。
3. 仅预览自评功能时，这是无后端 Demo；不需要云服务或合法域名。可选的心理健康资讯功能需要项目拥有者选择自己的 CloudBase 环境并部署 `healthNews`，再进行验证。
4. 编译成功后选择“预览”，用本地微信扫码。
5. 完成 7 题、查看结果并点击“重新测评”；三项都正常即预览验证通过。

## 公开发布

如需公开发布，必须使用你自己的微信公众平台账号完成实名、类目、隐私与审核要求。此项目默认仅用于本地预览，不会自动提交审核或发布。

若感到难以应对或有即时安全风险，请尽快联系当地紧急服务、心理危机支持机构或可信赖的人。

## 心理健康资讯（云开发）

资讯只读取[中国新闻网健康 RSS](https://www.chinanews.com.cn/rss/jk.xml)的标题、发布日期和原文链接；小程序不展示或存储正文、图片、摘要，也不会基于资讯给出医疗结论。

1. 在微信开发者工具打开本项目后，选择“云开发”，创建或选择自己的 CloudBase 环境。环境 ID 只保留在本地工具配置中，不写入代码。
2. 右键 `cloudfunctions/healthNews`，选择“在终端中打开”，运行 `npm install`，再选择“上传并部署：云端安装依赖”。
3. 云函数会创建或使用 `health_news_cache` 集合中 ID 为 `latest` 的缓存文档。该缓存只含公开资讯元数据和刷新时间，不含正文、图片或摘要。
4. 编译小程序，点击首页“查看心理健康资讯”，下拉刷新后确认最多显示 10 条标题。点击任一条会进入“资讯原文”页面；该页面会先说明原文暂不可用。
5. 若 RSS 暂时不可访问，页面会使用上一次成功缓存；若没有缓存，会显示“暂时无法加载资讯，请稍后重试。”，可点击“重新加载”。

### 原文链接的业务域名限制

`web-view` 打开中国新闻网原文前，必须由小程序项目主体在微信公众平台完成业务域名授权。阅读者无法自行授权中国新闻网域名。本 Demo 当前未满足这一前提，因此“资讯原文”页面会显示“原文暂不可用”，当前版本不会尝试打开中国新闻网原文；资讯仍只展示 RSS 的标题、发布日期和原始链接元数据。
