# 焦虑自评 Demo

这是一个本地使用的自我感受整理工具，不是医疗诊断；它不会收集、上传或保存答题数据。

## 自动验证

在本目录运行：

```bash
npm test
```

它会检查 7 道题、总分计算、各分数边界、页面注册及关键安全提示。

## 微信本地预览

1. 打开微信开发者工具，用自己的微信扫码登录。
2. 选择“导入项目”，项目目录选择本文件夹，开发模式选“小程序”。
3. 这是无后端 Demo；不需要云服务或合法域名。
4. 编译成功后选择“预览”，用本地微信扫码。
5. 完成 7 题、查看结果并点击“重新测评”；三项都正常即预览验证通过。

## 公开发布

如需公开发布，必须使用你自己的微信公众平台账号完成实名、类目、隐私与审核要求。此项目默认仅用于本地预览，不会自动提交审核或发布。

若感到难以应对或有即时安全风险，请尽快联系当地紧急服务、心理危机支持机构或可信赖的人。
